This repository contains all the materials used for code development and data handling throughout this project.
The code was developed based on the literature sources referenced in the thesis document (available soon) and in full compliance with legal and ethical research standards.
Code adjustments and improvements were made using ChatGPT-5 by OpenAI as a support tool.

Contents Overview

DataCollection.xlsx — Includes data extracted from the literature and two datasets used at different stages of the project. Each dataset is properly identified by the corresponding record numbers from their original databases.

Profiling.ipynb — Contains the implemented code for profiling and preprocessing applicable to any of the databases used in this study.

Baseline_Models.ipynb — Includes the baseline models explored for comparison and selection of the best-performing approaches.

5-Fold_Cross_Validation.ipynb — Refers to the methodology applied for model validation and performance evaluation.

Model Evaluation & XAI.ipynb — Focuses on the evaluation of the final model using the best-found parameters and includes the corresponding Explainable AI (XAI) analysis.
